- **Requested outcome:** Consider truncating or subsetting tributary watershed

- **Response / disposition:** Accept in modified form. Retain accurate,
  full-watershed boundaries rather than truncating them at dams. Add an
  optional, default-off **HRL flow-source reservoirs** reference layer to show
  the facilities that provide confirmed HRL flow contributions and make the
  downstream program focus legible. The initial layer will include only:

  - Shasta Dam / Shasta Reservoir
  - Oroville Dam / Lake Oroville
  - New Bullards Bar Dam / New Bullards Bar Reservoir
  - Folsom Dam / Folsom Lake
  - Camanche Dam / Camanche Reservoir
  - Don Pedro Dam / Don Pedro Reservoir
  - Monticello Dam / Lake Berryessa

  Do not include Friant at this time. Do not include the conditional upstream
  American River reservoirs or generic water purchase/export sources until a
  final, facility-specific commitment is available. Describe the layer as
  reference context only; it does not define a program boundary or evaluate
  fish passage.
- **Owner / follow-up:** Obtain authoritative point locations and confirm the
  names/labels; add the optional reference layer and test its presentation.

### F-28 — Use ecological bypass boundaries

- **Type:** Layer/source/design
- **Requested outcome:** Replace or supplement the representational Yolo and
  Sutter bypass boundaries with an ecological waterbody representation so their
  visual character better aligns with watershed layers. Candidate sources
  mentioned: Delta Historical Ecology / SFEI, historical ecology, and important
  waterways.
- **Response / disposition:** Defer. Retain the existing DWR bypass boundaries
  as the authoritative reference geometry. The available SFEI historical 
  ecology data do not provide a defensible ready-made ecological floodplain
  envelope for both bypasses: Yolo and Sutter are covered by different
  historical ecology projects with different vintages, coverage, and mapping
  approaches; the GIS consists of detailed historical habitat polygons rather
  than a bypass extent field; and historical ecology represents past landscape
  conditions rather than the bypasses’ current inundatable extent. Deriving one
  envelope would require subjective choices about habitat selection, clipping,
  gap closing, and generalization. The resulting geometry could appear
  authoritative while being an interpretation that conflicts with other
  authoritative DWR representations of the bypasses. Do not add a detailed
  ecological layer, which would be too visually noisy for this dashboard.
  Revisit only if an authoritative, purpose-built generalized floodplain extent
  becomes available.
- **Owner / follow-up:** Monitor for an authoritative generalized ecological
  floodplain dataset; otherwise retain the current DWR geometry.

### F-29 — Improve watershed and river system context

- **Type:** Layer/context
- **Requested outcome:** Add or improve watershed/river system context for
  project exploration. One reviewer found watershed outlines useful; another
  noted that individual river systems are not clear without labels.
- **Response / disposition:** Accept in modified form. Retain the existing
  optional HRL tributary watershed outlines and their individual controls.
  Improve river system orientation by making labels for named major HRL rivers
  and tributaries visible at a more useful overview zoom, while preserving the
  quieter default map and avoiding labels for watershed polygons. Watersheds
  are drainage area boundaries, not rivers; labeling each watershed polygon
  could misleadingly imply that its label names the local river system. Use the
  existing NHDPlus named-stream source rather than adding a new context
  dataset. Ensure the Layers panel and methodology clearly distinguish
  watershed boundaries from the stream network.
- **Owner / follow-up:** Adjust and visually test major-stream label
  thresholds, density, collision behavior, and contrast at the initial
  auto-fit extent and common project exploration zooms. Verify that
  Sacramento, American, Feather, Yuba, Putah, Mokelumne, and Tuolumne are
  readable where applicable without obscuring projects or creating label
  clutter. Update layer/help copy to distinguish drainage boundaries from
  stream lines.

### F-30 — Consider additional geographic context

- **Type:** Layer/context
- **Requested outcome:** Consider additional geographic context requested by

- **Response / disposition:** Accept in modified form. Improve the distinction
